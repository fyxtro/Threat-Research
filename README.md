# Threat-Research

This repository is used to publish research on threats observed in the wild.

## What to post

- Threat summaries
- Indicators of compromise (IOCs)
- Detection and hunting guidance
- Mitigations and response notes

## Suggested write-up format

1. Overview
2. Tactics, Techniques, and Procedures (TTPs)
3. IOCs
4. Detection
5. Mitigation
6. References
